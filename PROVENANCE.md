# What the public artifact preserves

`provenance/source_mapping.json` maps every copied/projected file to a logical original source ID, its original SHA-256, the public SHA-256, and the transformation. Source IDs use `project/` and `research_kit/`; they disclose no local filesystem location. A `byte-identical` entry is an exact original copy. A redacted or projected file has its own public hash and is never claimed to match the original bytes. `provenance/release_checksums.json` inventories the complete final release, excluding itself and ignored local/generated files.

The complete authored controlled fixture contains 24 fictional worlds, 144 candidate tasks, 144 gold records, and 48 alternative-span metadata records. The latter 48 are not model calls. The distinct rule-deletion experiment has 48 actual calls. Construction regeneration is compared against every saved object; unknown clauses or altered assembly fail validation. Controlled message hashes and all 432 corresponding model input-token sequences are checked without a tokenizer.

External projections preserve case IDs, original binary labels, source groups, data hashes, split, condition, verdicts, parse status, model identity, call/stage identity, token counts (including separately recorded EOS), stop reasons, timing, and decoding settings. Response/content fields and their token-ID arrays are omitted. SHA-256 commitments to removed fields retain provenance without redistributing or permitting reconstruction of the texts. Original private per-record hashes remain commitments; they cannot independently prove the omitted content without access to that content.

Public model manifests contain identifiers, revisions, and asset hashes only. They do not contain model/tokenizer assets. External full prompts contain source documents and summaries, so only exact instruction templates and request hashes are public. The independent prompt adapter was compared against 120 development and 300 final-test requests, including exact serialized messages and rendered hashes; the result is recorded in `provenance/prompt_equivalence.json`. After independent hydration, all 420 comparisons run again. The public CPU fixtures use only the authored fictional worlds.

No original predictions, prompts, labels, splits, final-test settings, or analyses were changed to create this package. No inference, relabeling, or new scientific experiment was run. The original research kit's implementation is omitted because its redistribution license has not been established. Its original baseline script SHA-256 is recorded; the new adapter is separately authored and hash-identified. The original project controlled source is retained in `reference_code/`; portable replay calls its pure analysis functions and never its inference entrypoints.

The published-table replay derives all ten numerical tables from frozen records, recomputes all 12 controlled paired contrasts (six family analyses plus six secondary scenario analyses), and recomputes all nine external metric comparisons with 10,000 paired bootstrap draws each. The two-call development cost counts both stages. Tests check exact fixture reconstruction, mutation rejection, frozen prompt/render fixtures, strict malformed-output behavior, token-difference truncation, scored outcomes and ablation scope, and complete hashes/lattices.

The original full audits additionally checked private external rendered prompts, token IDs, tokenizer decoding, local code hashes, and full collection ledgers. Public validation is narrower: it verifies the released measurement records and exact owned fixtures, not absent third-party files. Replaying historical token/time totals does not measure new runtime performance. Original 195 project and 13 kit tests belong to the historical study; the public package's eight regression tests are a separately stated suite.
